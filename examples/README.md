# A fictional job-search walkthrough

No credentials, live posts, real resume, or provider calls are used here. The examples below explain the output; they are not a live evaluation or an executable offline scoring mode.

## Input

Imagine a candidate with Node.js, Express, React, and SQL experience. Three fictional posts arrive:

1. “Hiring a junior Node.js developer. Express and SQL required. Apply at jobs@example.com.”
2. “Senior mobile engineer wanted: Swift and iOS, 6+ years.”
3. “I am looking for my next frontend role.”

## Illustrative result

The first post is a strong match to review, the second has a different stack and experience level, and the third is a job-seeker post rather than a vacancy. A model might return the structure in [sample-results.json](sample-results.json). The scores are hand-written examples, not measured model outputs.

The daily workflow saves progress and tracks duplicates. You still inspect the original post and decide whether to apply. Telegram reporting is optional; the tool does not apply to jobs for you.
